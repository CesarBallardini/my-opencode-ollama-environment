# Domains the local-llm profiles must never reach. A line covers the domain and all its
# subdomains ('openai.com' also refuses 'api.openai.com'). '#' starts a comment. Edited while
# the proxy runs: it re-reads this file on change, no restart needed.
#
# Matching is by whole labels from the right: an entry covers hosts that end with '.<entry>'.
# It does not cover a host whose first label merely contains the name, so a regional endpoint
# such as 'bedrock-runtime.us-east-1.amazonaws.com' is refused only because 'amazonaws.com'
# is listed. Raw IP addresses are matched exactly.
#
# The proxy refuses only what is listed here and lets everything else pass. This file is
# therefore defence in depth: it names every known model producer, LLM API, agent service and
# data sink, but it cannot name a host that does not exist yet, nor an arbitrary IP address.
# The air-gap-equivalent configuration is the allow list described in
# my-opencode-ollama-environment/2026-11-04-description.md, section 8.
#
# Extended on 2026-11-04. The original seven blocks are kept; the previous file is saved as
# egress-denylist.txt.2026-11-04.bak.
